SignSlator — Accuracy Report
============================

Generated by:  python run.py full-eval
Dataset:       ISL500 (HuggingFace: ISL500/ISL-DATA), signer ISL_DATA_USER001
Signs:         153
Templates:     605 (4 sessions per sign, a few with 3)

METHOD
------
Leave-one-out cross-validation with subsampling of competing signs.

For every template:
  1. it is held out
  2. it is matched against every other template of the SAME sign
  3. AND against one representative template of every OTHER sign
  4. the predicted sign is the nearest match (lowest DTW distance)

This is genuine generalization across sessions of the same signer — a template
is never scored against itself.

Feature pipeline: MediaPipe Holistic hand landmarks (21 per hand), wrist-centred
and scaled to palm size, so hand distance and hand size are removed before
comparison. Sequences are resampled to 64 frames for the DTW cost matrix.

CAVEAT
------
This measures accuracy WITHIN ONE SIGNER — the ISL500 dataset's performer.
Accuracy on a different person's hands is lower, because hand size, distance
from the camera, and signing style differ. The pipeline normalises for the
first two; the last is the remaining gap.

Measure accuracy on your own hands with:

    python run.py self-test
